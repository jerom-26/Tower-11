# Tower 11 – Development Roadmap

This roadmap outlines planned gameplay, technical, and deployment improvements for Tower 11.

## Short Term
- Add parallax scrolling background to enhance visual depth
- Improve explosion VFX on plane–tower collisions
- Implement sound effects for missiles, collisions, and scoring

## Mid Term
- Introduce dynamic difficulty scaling over time
- Polish UI for score display and game over screen
- Deploy a WebGL build
- Optimize Supabase leaderboard performance and security
- Add mobile-friendly control support
